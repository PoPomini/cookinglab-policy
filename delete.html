데이터 삭제 요청 방법

CookingLab(개발자: PoPomini)에는 계정이 없습니다. 게임 진행 데이터는 기기 안에만 있고 개발자에게 보내지 않습니다.

1. 기기에 저장된 게임 데이터 지우기 (바로 가능)

  1. 게임에서 설정 → 게임 초기화를 누르거나,
  2. 앱을 삭제하면 기기에 저장된 게임 데이터가 모두 지워집니다.

2. 개발자가 받은 데이터 삭제 요청 (이메일)

  1. 아래 주소로 이메일을 보냅니다. 제목: [CookingLab] 데이터 삭제 요청
  2. 본문에 지워 줄 데이터를 적습니다.
    • 문의 메일: 문의할 때 쓴 이메일 주소
    • 비공개 테스트 기록: 테스트 때 입력한 닉네임
  3. 개발자가 확인 후 10일 안에 삭제하고 결과를 답장으로 알려 드립니다.

How to request data deletion

CookingLab (developer: PoPomini) has no accounts. Your game progress is stored only on your device and is never sent to the developer.

1. Delete game data on your device (instant)

  1. Tap Settings → Reset Game in the game, or
  2. uninstall the app. All game data stored on the device is deleted.

2. Ask the developer to delete data we received (email)

  1. Email the address below with the subject [CookingLab] Data deletion request.
  2. Tell us which data to delete:
    • Support emails: the email address you wrote from
    • Closed-test records: the nickname you entered during the test
  3. We will delete it within 10 days and confirm by reply.

rioh3021@gmail.com

No data is kept for legal reasons, and nothing is retained after deletion.

4. Advertising data (Google AdMob)

Ad-related data (such as the advertising ID) is collected and managed by Google, so the developer cannot delete it. You can delete or reset your advertising ID in your device's Settings → Google → Ads (may differ by device). More: https://policies.google.com/technologies/partner-sites
